# Changelog

All notable changes to **Aether SDK** are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- `muninn-aether-core`: Pure domain contracts, validated newtypes (`ProjectId`, `MemoryId`, `EntityId`, `UserId`, `SessionId`), `DistanceMetric::score`, `FilterExpr::matches`, `IndexSpec`, `SecretString`, `redact_url_userinfo`, `AetherError`, and `OutboundConnector`, `RecordStore`, `VectorStore`, and `GraphStore` traits.
- `muninn-aether-cortex`: Durable `RecordStore`-driven `Indexer` sync engine (`run_pass`, `apply`, opt-in `spawn`), `PersonalizedPageRank` + `graph_scores`, and `recall` primitives (`vector_search`, `graph_search`, `unindexed`, `session`, `merge`, `rrf`).
- `muninn-aether-adapters`: `InMemoryBackend` with `FaultPoint` injection, `Batcher`, `Timeout`, `Resilient` (exponential backoff with full `jittered` delay), `Traced`, reusable `contract` test suite (`contract-suite`), and feature-gated backend drivers (`sqlite`, `redis`, `qdrant`, `pgvector`, `chroma`, `turbopuffer`, `neo4j`).
- `muninn-aether-sdk`: Optional `MemoryManager` and `MemoryManagerBuilder` facade, runnable examples (`level_1_connector` through `level_5_facade`, `otel_demo`), and optional OpenTelemetry OTLP preset (`otel` feature).
- `muninn-aether-vault`: Obsidian-native vault daemon (`VaultEngine`), YAML frontmatter and fenced-code-aware Markdown parser with `aether_tier: private` and `.aetherignore` exclusions, single-file SQLite WAL (schema `v3`) + FTS5 + `PersonalizedPageRank` + `CrossEncoderReranker` hybrid recall, pluggable `Embedder` (`HashedNgramEmbedder`, `DenseSubwordEmbedder`, `LocalGpuEmbedder`) with `vault_meta` sync/shadow-swap auto-reindexing, deterministic `HOT` prefix packing (`static_prefix` / `dynamic_context` separation), atomic `Aether/Inbox.md` staging and `Aether/Compiled/Approved.md` compiled mirror with `self_write_ledger` loop prevention, incremental Daily Note Dream consolidation (`dream_watermarks`), per-agent scoped API keys (`AgentId`, `AgentRole`, `ScopeTag`, `aek_<hex>` stored as domain-separated SHA-256 hashes in `agent_api_keys`), Git-backed team vault sync (`VaultEngine::git_sync`) with monotonic lattice resolution (`Approved > Rejected > Pending`) and credential redaction, vLLM/SGLang + LMCache KV-tensor warming (`InMemoryKvCacheAdapter`, `VllmLmCacheHttpAdapter`, PagedAttention chained prefix blocks + CacheBlend AMU chunks persisted in `kv_cache_blocks` with atomic eviction), authenticated HTTP control plane (`ControlPlaneServer::bind_with_auth` with `/v1/recall`, `/v1/stage`, `/v1/inspect`, `/v1/mcp`, `/v1/git/sync`, `/v1/kv/warm`, `/v1/kv/stats`, `/v1/auth/keys`, `/v1/auth/keys/revoke`), scoped `McpServer` (`kv_model`/`kv_hint` and `agent.default_write_scope()`), and CLI flags (`--require-auth`, `--bootstrap-admin-key`, `--api-key`, `--kv-endpoint`, `--kv-model`).
- `obsidian-aether-plugin`: TypeScript Obsidian companion plugin (`AetherControlClient` with `AetherClientOptions`, remote HTTPS + bearer auth policy, `assertControlPlaneBaseUrl`, status bar indicator, 1-click Inbox review controller/pane, `"Trigger Dream Pass"`, `"Git Sync Team Vault"`, and `"Warm GPU KV Cache"` commands).
- Documentation portal built with Docusaurus in `website/`, local Docker dev stack in `infra/`, and CI gates for Rust (`rustfmt`, `clippy`, tests), website build, and `gitleaks` secret scanning.
