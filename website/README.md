# Aether SDK Documentation Site

The documentation portal and landing page for **Aether SDK** are built with [Docusaurus](https://docusaurus.io/) and deployed via [`.github/workflows/docs.yml`](../.github/workflows/docs.yml).

## Local Development

```bash
npm ci
npm run start
```

## Typecheck and Build

```bash
npm run typecheck
npm run build
```

## Tests

```bash
npm test
```
